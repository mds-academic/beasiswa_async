Apa Itu Google Colaboratory (Google Colab)? ☁️

Google Colab (kependekan dari Colaboratory) adalah aplikasi berbasis web yang disediakan gratis oleh Google untuk menulis dan menjalankan kode program Python langsung di browser internet.

  • Zero Installation: Kamu tidak perlu menginstal Python, Anaconda, atau VS Code di komputer atau laptopmu.
  • Cloud Powered: Kode dijalankan di komputer server Google berkemampuan tinggi secara gratis.
  • Google Drive Autosave: Semua catatan dan kodinganmu langsung tersimpan aman di Google Drive akun pribadimu.
  • Multi-device: Bisa diakses lancar dari laptop Windows, MacBook, Chromebook, hingga tablet!

Dengan Google Colab, kita bisa fokus 100% belajar logika koding tanpa pusing kendala laptop lemot atau instalasi error! 🎉

Google Colab vs Jupyter Notebook Lokal ⚖️

Para developer profesional sering membandingkan Google Colab dengan Jupyter Notebook. Berikut perbandingan utamanya agar kamu paham:

Fitur / Aspek Google Colaboratory (Cloud) Jupyter Notebook (Lokal)
Penyimpanan File Otomatis tersimpan di Google Drive Tersimpan di harddisk komputer fisik
Instalasi & Setup Langsung pakai via browser web Wajib install Python & environment rumit
Hardware & Memori Gratis RAM hingga 12GB & GPU Cloud Bergantung penuh pada spek laptop sendiri
Kolaborasi & Sharing Sangat mudah, cukup bagikan link (ala Google Docs) Perlu kirim file manual atau setup Git server

Oleh karena itu, Google Colab adalah pilihan paling ideal dan nyaman untuk pembelajaran asinkronus kita!

Langkah 1: Membuka Colab & Membuat Notebook Baru 🌐

Mari kita mulai! Ikuti langkah-langkah praktis berikut:

  • Buka peramban (Chrome / Edge / Safari) lalu kunjungi alamat: https://colab.research.google.com/
  • Pastikan kamu sudah login ke akun Google kamu (Gmail).
  • Akan muncul dialog selamat datang. Klik tombol biru + New notebook (atau + Notebook baru).
📸 Tangkapan layar nyata: Halaman selamat datang Google Colab dengan tombol "+ New notebook" di pojok kiri atas.

Langkah 2: Anatomi Area Kerja Google Colab 🖥️

Setelah notebook terbuka, mari kenali bagian-bagian penting di layar kerjamu:

📸 Tangkapan layar nyata: Antarmuka interaktif Google Colab yang memuat menubar, code cells, dan output langsung.
  • Judul File Notebook: Di kiri atas (misal Untitled.ipynb). Klik untuk mengganti nama file.
  • Tombol + Code & + Text: Untuk menambahkan baris perintah kode baru atau teks catatan.
  • Indikator Connect / Runtime: Di pojok kanan atas, menandakan status koneksi ke komputer cloud Google (RAM & Disk).
  • Sidebar Kiri: Menu navigasi daftar isi, pencarian kode, dan penjelajah file Google Drive.

Langkah 3: Memahami Code Cell vs Text Cell 📝

Di Google Colab, dokumen disusun dari blok-blok yang disebut Cell. Ada dua jenis cell:

💻 1. Code Cell (Sel Kode)

Blok berwarna abu-abu gelap dengan tombol Play ▶️ di kirinya. Di sinilah kita mengetik instruksi Python yang akan dihitung dan dijalankan oleh komputer.

print("Ini dijalankan komputer!")
📄 2. Text Cell (Sel Teks)

Blok untuk menulis penjelasan, judul modul, catatan rumus, atau dokumentasi menggunakan format teks kaya Markdown.

# Catatan Modul: Pengeluaran Harian
"Kombinasi Code dan Text Cell menjadikan Colab bukan hanya buku catatan pasif, melainkan laboratorium digital yang hidup!" 🧪

Langkah 4: Menulis Perintah Pertama — Fungsi print() 📢

Perintah paling mendasar di Python adalah fungsi print(). Perintah ini digunakan untuk menampilkan pesan atau hasil hitungan ke layar.

Mari perhatikan aturan sintaksnya:

# Menampilkan pesan teks (wajib pakai tanda petik ganda atau tunggal)
print("Halo Dunia! Selamat Datang di Python SMA")

# Menampilkan angka matematis (tidak perlu tanda petik)
print(24 * 60 * 60)
📸 Tangkapan layar nyata: Menghitung detik dalam sehari (24 * 60 * 60) dan menghasilkan output 86400 tepat di bawahnya.

Langkah 5: Cara Menjalankan Kode (Shortcut Sakti) ⚡

Ada 3 cara untuk mengeksekusi kode yang sudah kamu tulis di dalam Code Cell:

▶️
Cara 1: Klik Tombol Play
Arahkan kursor mouse ke lingkaran tombol Play di samping kiri cell, lalu klik sekali.
Shift + Enter
Cara 2: Shortcut Keyboard Sakti (Paling Direkomendasikan!)
Jalankan cell yang aktif, dan otomatis berpindah/membuat cell baru di bawahnya. Cepat dan efisien!
Ctrl + Enter
Cara 3: Run di Tempat
Jalankan cell yang aktif tanpa memindahkan fokus kursor ke bawah.

Langkah 6: Mengenal Konsep Variabel 📦

Bayangkan kamu memiliki sebuah kotak penyimpanan yang diberi label nama. Kamu bisa memasukkan barang ke dalamnya, mengambilnya kapan saja, atau mengganti isinya. Itulah Variabel!

# Membuat variabel untuk data keuangan kita
nama_akun = "Ahmad Yazid"
saldo_awal = 500000
pengeluaran = 75000

# Menghitung sisa saldo dengan operasi matematika
sisa_saldo = saldo_awal - pengeluaran

print("Nama Akun:", nama_akun)
print("Sisa Saldo Kamu: Rp", sisa_saldo)
⚠️ Aturan Penamaan Variabel di Python:
• Gunakan huruf kecil dan pisahkan kata dengan underscore _ (contoh: total_belanja).
• Tidak boleh memakai spasi (❌ total belanja).
• Tidak boleh diawali angka (❌ 1transaksi).

Langkah 7: 4 Tipe Data Utama di Python 🏷️

Setiap data yang dimasukkan ke komputer memiliki jenis atau Tipe Data. Dalam aplikasi pencatatan keuangan kita nanti, 4 tipe ini adalah yang paling sering digunakan:

Tipe Data Nama Lengkap Penjelasan Sederhana Contoh di Kode
str String (Teks) Kumpulan huruf/kata diapit tanda petik "UOB Finance"
int Integer (Bilangan Bulat) Angka tanpa tanda koma/desimal 150000
float Floating Point (Desimal) Angka pecahan memakai titik (.) 2.5 atau 17.8
bool Boolean (Logika) Hanya bernilai Benar atau Salah True atau False

Ingat: Angka yang diapit tanda petik seperti "50000" akan dianggap sebagai teks (string) dan tidak bisa dijumlahkan secara matematika sebelum diubah ke integer!

Glosarium Cepat & Tips Anti-Error 💡

Simpan rangkuman istilah penting ini sebagai bekal perjalanan kodingmu:

.ipynb
Format berkas Interactive Python Notebook yang memuat kode dan teks sekaligus.
Runtime
Lingkungan komputasi di server Google yang memproses dan mengeksekusi kode Python kita.
SyntaxError
Pesan error jika ada salah ketik tanda kurung, tanda petik yang belum ditutup, atau huruf typo.
Case-Sensitive
Python membedakan huruf besar dan kecil. print() benar, tetapi Print() akan error!
🛡️ Golden Rule Programmer: "Menemukan pesan error di terminal bukan tanda kamu gagal, melainkan petunjuk cerdas dari komputer agar kodemu menjadi sempurna!"
