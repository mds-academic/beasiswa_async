Game membutuhkan input

Game terasa interaktif karena program menunggu input pemain: menekan tombol panah, mengeklik Sprite, atau menyentuh objek.

when [up arrow] key pressed
move (10) steps

Gerak sambil tombol ditekan

when [up arrow] key pressed
repeat until <not key [up arrow] pressed?>
move (10) steps

Program memeriksa apakah tombol masih ditekan. Ini membuat mobil dapat bergerak dengan lebih halus.

Sensing bertanya kepada Stage

touching [Finish Line]?Apakah mobil menyentuh garis finish?
touching [Mobil 2]?Apakah dua mobil bertabrakan?
key [space] pressed?Apakah tombol tertentu sedang ditekan?

Sensing biasanya perlu dicek berulang agar tidak hanya memeriksa satu kali.

If membuat aturan game

when green flag clicked
forever
if <touching [Finish Line]?> then
say [Aku menang!] for (2) seconds
stop [all]

Kalimatnya bisa dibaca: jika menyentuh finish, maka jalankan aksi menang.

Racing Car: urutan kerja

  1. Desain sirkuit dan garis finish.
  2. Desain mobil dan atur arah.
  3. Program input keyboard dan gerak.
  4. Duplikasi mobil kedua dan ubah kontrol.
  5. Tambahkan collision dan feedback menang.
