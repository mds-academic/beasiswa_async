💡 Pola Pikir Komputer

Cara Komputer Berpikir: Siklus I-P-O

⌨️
1. Input (Masukan) Instruksi atau data mentah yang kita ketikkan melalui keyboard.
⚙️
2. Proses (Pengolahan) Mesin Python menerjemahkan instruksimu baris demi baris dan menjalankannya.
🖥️
3. Output (Keluaran) Hasil akhir yang ditampilkan ke layar monitor agar bisa dibaca manusia.
🎯 Komputer hanya melakukan apa yang kamu perintahkan. Jika instruksimu teratur, hasilnya pasti teratur!

📝 Menulis Perintah

Mengenal Code Cell & Fungsi print()

📦
Code Cell (Kotak Perintah) Kotak abu-abu tempat kamu mengetikkan baris perintah Python.
📢
Fungsi print() Perintah ajaib untuk menyuruh komputer mencetak teks ke layar. Teks wajib diapit tanda petik ("...").
⚠️ Aturan Tanda Petik: Huruf atau kalimat wajib memakai tanda petik dua "Halo" atau petik satu 'Halo'.
🔍 Klik untuk Perbesar

📸 Code Editor: Mengetik Perintah print() di dalam Code Cell

▶️ Eksekusi Kode

Menjalankan Kode & Membaca Output

🔘
Tombol Play (Run) Klik tombol lingkaran segitiga di samping kiri cell, atau gunakan shortcut keyboard Ctrl + Enter.
👀
Membaca Hasil di Bawah Cell Teks hasil print akan muncul bersih tepat di bawah kotak kode cell dalam hitungan detik.
🎉 Selamat! Ketika teks muncul di layar, kamu sudah resmi menjadi seorang Coder Python!

📖 Rangkuman Ringkas Materi

Google Colab adalah editor Python berbasis web gratis yang tidak memerlukan instalasi aplikasi di laptop. Siswa menulis perintah di dalam Code Cell, menekan tombol Run (Play), dan membaca hasilnya (Output) tepat di bawah cell. Perintah print("teks") digunakan untuk menampilkan teks ke layar. Pahami siklus Input ➔ Proses ➔ Output sebelum melangkah ke koding yang lebih kompleks!
