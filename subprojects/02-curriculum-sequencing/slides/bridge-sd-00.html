Selamat datang di Scratch

Scratch adalah tempat untuk membuat cerita, animasi, dan game dengan menyusun balok kode seperti puzzle.

Hari ini kita tidak mengejar project besar. Kita belajar mengenali tempat bermainnya dulu, lalu membuat satu Sprite melakukan satu aksi.
🎨 BuatKamu memilih ide, karakter, dan latar.
🧩 SusunKamu menyambungkan blok kode.
▶️ UjiKamu menjalankan, mengamati, lalu memperbaiki.

Masuk ke ruang kerja Scratch

  1. Buka scratch.mit.edu di browser.
  2. Pilih Create untuk membuat project.
  3. Masuk akun agar project bisa disimpan dan dilanjutkan.
  4. Mulai dari project kosong atau remix starter project jika diberikan guru.
Jangan membagikan nama lengkap, alamat, password, atau data pribadi di project publik.

Kenali 4 area utama

1. Block PaletteKiri: tempat mengambil blok kode berwarna.
2. Coding AreaTengah: tempat menyusun dan menyambungkan blok.
3. StageKanan atas: tempat melihat project berjalan.
4. Sprite & BackdropKanan bawah: tempat mengatur karakter dan latar.

Klik Sprite terlebih dahulu sebelum menulis kode. Kode yang kamu susun akan mengatur Sprite yang sedang dipilih.
